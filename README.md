# 梁志聪的个人网站

以[DevPortfolio](https://github.com/RyanFitzgerald/devportfolio)为底版，加入中文内容、真实作品截图、演示链接与教学实践。原模板使用Astro与Tailwind CSS，MIT许可证保留在LICENSE.md。

网站内容与链接可在`src/config.ts`维护；下方个人经历、教学介绍在对应Astro组件中。公开简介在`public/profile.html`，不包含手机号或推荐人联系方式。

公开网址：https://uuoov.github.io/ 。源码在main分支，生成的静态网站在gh-pages分支。

## 本地查看

安装：`npm ci`。预览：`npm run dev`。生成网站：`npm run build`。生成结果在`dist/`。

## 资料与作品

核对记录见`docs/SOURCES.md`。简历平台图片取自本人的公开仓库演示数据；课堂平台截图仅保留首页功能与统计，不展示学生姓名或反馈。

旧版申请简历PDF包含后续已更正的项目叙述，不直接作为本站下载文件。访客可以查看一页简介，并在浏览器打印为PDF。
